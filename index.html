NEW EMPLOYEE ORIENTATION · FORM 42-A

How to investigate an anomaly

YOUR JOB: FIND WHICH ONE OF THE FOUR RULES IS TRUE.

You get up to 3 tests. Each test combines one specimen with one procedure. The result is either SAFE or BREACH. Use those results to eliminate rules that cannot be true.

1
READ THE FOUR RULES

Do this first. You are not guessing blindly — you are testing four specific theories.

2
CHOOSE A TEST THAT TELLS YOU SOMETHING

Pick one specimen and one procedure, then press RUN PROCEDURE.

Example: suppose you want to test the theory “Anything put in the Filing Drawer breaches.” Put an ordinary specimen in the Filing Drawer. If the result is SAFE ○, that theory cannot be correct.
3
USE UP TO THREE RESULTS, THEN SUBMIT A RULE

You can change your selected rule at any time. Once confident, submit it.

4
FINAL CHECK

Apply your chosen rule to three new specimens. Pick the one that should breach.

SAFE ○ = the rule condition was NOT triggeredBREACH ✕ = the rule condition WAS triggered
That's it: read the theories → run useful tests → eliminate wrong rules → submit your answer.
